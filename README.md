EduBank merupakan aplikasi mobile yang di kembangkan untuk merapikan pengelolaan modul ajar dan bank soal Kurikulum Merdeka, khususnya pada jenjang SD. Ide dasarnya sederhana, daripada pendidik harus bolak-balik mencari catatan CP, TP, ATP, dan arsip soal latihan di banyak perangkat, semuanya dikumpulkan agar bisa dilihat, ditambah, diedit, atau dihapus lewat satu aplikasi saja. Tampilan aplikasinya dibangun menggunakan React Native dengan Expo sampai tahap build APK, sementara sisi servernya memakai Express.js dan PostgreSQL Supabase agar seluruh perubahan data tersimpan secara online.
